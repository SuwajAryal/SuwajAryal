# Suwaj Aryal

I’m a civil engineer working on water resources and hydropower. My research uses hydraulics and machine learning to study how rivers move sediment, with a focus on Himalayan catchments.

[Portfolio and CV](https://suwajaryal.github.io/) · [Research and thesis](https://suwajaryal.github.io/#research) · [Publications](https://suwajaryal.github.io/#publications) · [Education](https://suwajaryal.github.io/#education)

## Thesis and research

- [Physics-guided suspended sediment prediction](https://github.com/SuwajAryal/Suspended_Sediment_prediction_PGNN) compares a physics-guided neural network with an unconstrained model.
- [Suspended sediment baselines](https://github.com/SuwajAryal/Suspended_Sediment_prediction_other_model) contains the companion neural and conventional machine-learning comparisons.
- [Jalkundi notebooks](https://github.com/SuwajAryal/models-Reliability) explore sediment data and set up a K-nearest neighbors experiment.

## Practical tools

- [Reservoir operation and water allocation](https://github.com/SuwajAryal/Dynamic_programming_optimization) explores two water-management problems with dynamic programming.
